# 🏧 ATM Application

A console-based ATM simulation built in Java.

## 🛠️ Built With
- Java
- OOP Concepts

## 📌 Features
- Deposit money
- Withdraw money
- Check balance
- Change PIN
- PIN authentication for all transactions

## ▶️ How to Run
1. Open terminal
2. Compile: `javac ATM.java`
3. Run: `java ATM`

## 🚀 What I Learned
- Object Oriented Programming in Java
- Classes, methods and constructors
- User input handling with Scanner
- Conditional logic and switch statements
